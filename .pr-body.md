## Summary

- Preserve an empty cwd tombstone after Git unregisters an isolated worktree so Codex Stop hooks can still start.
- Replace that tombstone safely with a real linked worktree when the same issue is run again.
- Add a regression that reproduces the issue #135 teardown sequence.

```acceptance
GIVEN a DevOps subagent running inside its isolated issue worktree
WHEN it unregisters that worktree before Codex executes Stop hooks
THEN the recorded cwd remains spawnable and a future run can recreate the linked worktree safely
```

- [x] `otta-worktree.sh --remove` removes the checkout from Git worktree state while leaving the recorded cwd path spawnable until process teardown.
- [x] A later create for the same issue replaces the teardown tombstone with a valid Git worktree.
- [x] The regression test proves a command can start from the path after removal and proves the recreated path is a Git worktree.
- [x] Existing worktree behavior remains passing.
