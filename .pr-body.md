## Summary

- Add `scripts/otta-pulse-doctor.sh` to verify Otta Pulse GitHub App installation permissions with App JWT auth.
- Add `/otta:pulse-doctor` command docs and README usage.
- Cover missing credentials, `checks:write`, and `checks:read` repair paths with hermetic tests.

```acceptance
GIVEN a repo with Otta Pulse installed
WHEN a developer runs the Pulse doctor with App credentials
THEN it verifies the app installation and reports whether checks:write is available without printing tokens
```

- [x] AC1 `[data-layer]`: Add a script that accepts an owner/repo and GitHub App credentials, creates a JWT, finds the repo installation, mints an installation token, and verifies `checks: write`.
- [x] AC2 `[data-layer]`: Missing App credentials must fail with a clear message explaining that a normal `gh` user token is not enough for this diagnostic.
- [x] AC3 `[data-layer]`: A `checks: read` installation must fail with a repair instruction to update the App permission to Checks: Read and write and re-accept the installation.
- [x] AC4 `[data-layer]`: Add a slash-command surface and README docs for the doctor command, including the required env vars and token-redaction behavior.
- [x] AC5 `[data-layer]`: Add hermetic tests using fake `gh`, `curl`, and `openssl`, with no real GitHub App secrets or network calls.
