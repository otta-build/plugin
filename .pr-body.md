## Summary

- `.pr-body.md` is tracked and survives merges, so a leftover body from a previous PR can get silently reused (this literally just happened: otta-build/dev#19 reused a stale `Fixes #17` body — #17 was already closed).
- `check-pr-body.sh` (run by `otta-gate.sh` on every push) now best-effort checks whether the issue in `Fixes #N` is already CLOSED via `gh`, and fails with a clear reseed instruction if so. Degrades gracefully (passes) if `gh` is unavailable/unauthenticated — no hard network dependency.

```acceptance
GIVEN .pr-body.md references an issue via Fixes #N
WHEN check-pr-body.sh (part of otta-gate.sh) runs
THEN it fails with a clear message if issue #N is already CLOSED, passes if OPEN, and degrades gracefully (passes) if gh is unavailable/unauthenticated

- [x] AC1 `[data-layer]`: Given .pr-body.md with Fixes #N where issue #N is CLOSED, then check-pr-body.sh fails mentioning "already CLOSED". — bash tests/check-pr-body-stale-issue.test.sh (check 1)
- [x] AC2 `[data-layer]`: Given .pr-body.md with Fixes #N where issue #N is OPEN, then check-pr-body.sh passes. — bash tests/check-pr-body-stale-issue.test.sh (check 2)
- [x] AC3 `[data-layer]`: Given gh is unavailable, then check-pr-body.sh still passes (best-effort, no network dependency). — bash tests/check-pr-body-stale-issue.test.sh (check 3)
```
