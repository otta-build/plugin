## Summary

- `tests/ledger-stream.test.sh`'s `nc_listen` now polls (`lsof -sTCP:LISTEN`, falling back to `nc -z`) until the listener is actually bound, bounded to 20 x 0.1s, instead of a fixed `sleep 0.05`.
- Fixes a second, related race uncovered while reproducing the flake: `nc -l` relays bidirectionally (stdin -> socket), so when its stdin is already at EOF (as under a non-interactive test run) it can shut the connection down before finishing the write to the log file — independent of the bind-timing race. `nc_listen` now feeds nc's stdin from a long-lived `sleep 30` so it only closes because the peer (curl) closed the connection.
- Test 4 now polls for the log file to become non-empty (bounded) instead of a single fixed `sleep 0.5` before checking it.
