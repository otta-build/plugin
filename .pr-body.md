# fix(gate): no-origin-tolerant BASE detection (don't crash on fresh/local repos)

Found by the **fresh-repo onboarding test** (universal-tool validation). `check-test-coverage.sh` computed BASE via `git symbolic-ref ...origin/HEAD | sed` under `set -euo pipefail`. On a repo with **no `origin/HEAD`** — a fresh clone or a local-only repo, i.e. any team's very first run — that pipeline fails and `set -e` **aborts the gate silently** (looks like a crash, not a clean verdict).

Fix: BASE detection now degrades — origin default branch → local default branch → repo root commit — and the symbolic-ref pipeline carries `|| true` so it never aborts.

```acceptance
- [x] AC1: no origin/HEAD + a test in the diff → gate passes (exit 0), no crash
- [x] AC2: no origin/HEAD + no test + no [test-impractical] → clean fail (exit 1), not an abort
- [x] AC3: empty diff still → "no changes to gate yet" (exit 0); origin-present behavior unchanged
- [x] AC4: regression test tests/check-test-coverage-no-origin.test.sh (3/3 pass)
```
