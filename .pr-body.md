Issue #184 has been corrected and the bogus acceptance criterion removed. No stdin change is made here.

## Two things for a follow-up, deliberately not folded in

**1. The shellcheck gate does not cover `tests/`.** Its glob is `scripts/*.sh hooks/*.sh`, so moving this file out of `hooks/` technically drops it from lint coverage. I verified it is still clean at warning severity, so nothing regressed here — but expanding the gate to `tests/` is not free:

**2. That single error is real.** `tests/otta-worktree-concurrent.test.sh:35`:

```sh
[ -e "$TMP/wts"/*"-$n/.git" ] || fail "worktree for issue $n missing"
```

SC2144 — `-e` does not work with globs. It passes today only because the glob happens to match exactly one path. Two matches and `[` fails with "too many arguments", turning a real assertion into a confusing error. Zero matches happens to behave correctly (the glob stays literal, `-e` is false, `fail` fires), which is why this has never been noticed.

Worth its own PR alongside the 19 warnings.
