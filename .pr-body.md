# fix(setup): telemetry consent must disclose data destination (#24)

The `/otta:setup` step-8 telemetry consent (v0.13.0) stated the *process-level scope* ("every CC session in this repo emits") but not the **data destination**. Default endpoint is `https://pulse.otta.build` — Otta's hosted server — so a customer opting in without self-hosting was sending their CC session telemetry to us without being told at consent time. For a tool positioned on neutrality + governance, that's a trust gap. This adds the destination disclosure to the consent prompt + README.
