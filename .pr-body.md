## The 18, by category

**Real hardening — 7× SC2164** (`cd` without `|| exit`), in `check-test-coverage-no-origin.test.sh` (4) and `otta-gate-glob.test.sh` (3). Each `cd` is into a `mktemp -d` inside a subshell, so the failure path is not reachable today; the fix costs nothing and removes the class.

**Dead variables — 2× SC2034.** `for i in $(seq 1 30)` where `i` is never used, in `e2e-session-link.test.sh` and `otta-telemetry-setup.test.sh` → `for _ in`.

**False positives — 9, each disabled by line with a comment saying why:**

| finding | why the code is right |
|---|---|
| 5× SC1007 (`otta-codex-setup`, `otta-deploy-verify`, `otta-gemini-setup` ×2) | `OTTA_PULSE_TOKEN= bash "$SCRIPT"` is an intentional empty-value env prefix for a single command. Setting the variable empty **is the thing under test** — these cases assert the script rejects a missing token. |
| 1× SC2088 (`codex-breaking-guards`) | The tilde is inside the literal string being *searched for* (`grep -rlF '~/.codex/prompts'`), not a path this script dereferences. Expanding to `$HOME` would make the guard hunt for the caller's home directory instead of the text it exists to forbid. |
| SC2089 + SC2090 (`ledger-append`) | `$bad_args` is deliberately unquoted so `'--input NaN'` reaches the script as two argv entries. Quoting it would pass one argument, the script would reject it for the *wrong reason*, and the test would keep passing while checking nothing. |
| 1× SC1090 (`github-workflow-latest-wins`) | The sourced path is resolved at runtime. It is linted directly by the gate's `scripts/*.sh` glob, so following it here adds nothing. |
