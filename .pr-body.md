# docs: document OTTA_PULSE_URL self-host override (universal setup)

Otta is a universal, multi-team tool — any team should be able to point the loop at its own Pulse. The override already exists (`PULSE_URL="${OTTA_PULSE_URL:-https://pulse.otta.build}"` in pulse-install.sh) but was **undocumented**, so a self-hosting team couldn't discover it. Documents it in `/otta:setup` (step 3) and the README, with copy-paste examples. No code change — closes a discoverability gap, not a missing feature.
