## Summary

- Add a minimal `/otta:remember` command + `scripts/otta-remember.sh` that promotes a signal-gated learning (decision | gotcha | failed-approach only) into a repo-local human-readable `LEARNINGS.md` — mirroring the brain `/remember` signal gate
- Build-triggers from the issue are now met: gate is blocking, ≥5 PRs produced verdicts, and ≥1 escape the LEARN layer did not auto-capture (the CC-emits-metrics-not-logs bug — a green gate shipped an empty /compare). This MVP is the smallest non-duplicative slice; it does NOT create a competing telemetry store

```acceptance
GIVEN a repo using the Otta plugin
WHEN  a developer runs the otta-remember script with a category (decision|gotcha|failed-approach) and a learning text
THEN  a structured dated entry is appended to repo-root LEARNINGS.md (file created if absent), invalid categories are rejected, and exact-duplicate entries are not appended twice

- [x] AC1: scripts/otta-remember.sh <category> <text> appends a dated entry "## <DATE> [<category>] <text>" (or similar structured line) to ./LEARNINGS.md; creates the file with a header if it does not exist
- [x] AC2: category is gated to exactly {decision, gotcha, failed-approach}; any other category exits non-zero with a usage error and writes nothing (mirrors the brain signal gate)
- [x] AC3: idempotent on exact duplicate — re-running with the same category+text does not append a second identical entry
- [x] AC4: commands/remember.md exists with frontmatter (description + argument-hint) instructing the agent to signal-gate then call the script via ${CLAUDE_PLUGIN_ROOT}/scripts/otta-remember.sh
- [x] AC5: tests/otta-remember.test.sh covers AC1–AC3 (append+create, category gate reject, dedup) and passes

## Out of scope (explicitly deferred — design-open per the issue)
- Auto-capture from gate verdicts (this MVP is human-invoked only)
- `.otta/memory/` structured store (LEARNINGS.md chosen for simplicity / human-readability / no competing DB)
- Dedup/reconciliation against the Pulse LEARN ledger or GEPA (different layer: local human-curated vs telemetry-derived)
```
