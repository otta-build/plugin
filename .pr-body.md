## Summary

- Adds `scripts/detect-harnesses.sh` — a standalone script that detects which AI coding harnesses (Claude Code, Codex, Gemini, Cursor) are configured in a repo, using per-repo config file markers (not CLI presence) to avoid false positives.
- Extends `/otta:setup` with step 9b: multi-harness detection prompts, and step B1b + B6: OTTA.md → harness context file mapper that writes `CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, or `.cursor/rules` with Otta boilerplate, never overwriting existing files.
- Adds 9-check test suite `tests/detect-harnesses.test.sh` covering all four harnesses, multi-harness, empty repo, clean output format, and no false-positives from CLI-only installs.
