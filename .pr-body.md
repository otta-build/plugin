```acceptance
GIVEN a PR opened by `scripts/seed-pr-body.sh`
WHEN the body is rendered on GitHub
THEN the acceptance-criteria checkbox list, "Out of scope", and "Verification" sections render as real markdown (headers/checkboxes), NOT flattened inside the ```acceptance fence — only GIVEN/WHEN/THEN stays inside the fence

GIVEN `scripts/otta-deploy-verify.sh` is polling the gate or a Coolify deploy
WHEN the poll loop runs longer than one interval
THEN it prints a status line at most once every 60s (or only on state change) instead of once per 10-15s tick

GIVEN `scripts/otta-gate.sh` runs (directly, or silently re-invoked by `hooks/subagent-gate-guard.sh` / `hooks/pre-push-guard.sh`)
WHEN its sub-checks print their success/failure lines
THEN each line is prefixed with a consistent stage tag (e.g. `[otta-gate:pr-body]`)
AND the hooks print a one-line banner before invoking the gate silently on success

GIVEN `workflows/otta-build.mjs` dispatches subagents via its `agent()` helper
WHEN a subagent completes and the harness surfaces a "Teammate @<name> finished" notification
THEN the notification shows a human-readable stage name, not an opaque hash

GIVEN gate scripts print status glyphs
WHEN scanning gate output end-to-end
THEN success/warning/fail glyphs and label prefixes are consistent across check-pr-body.sh, check-test-coverage.sh, check-ac-layers.sh
```
