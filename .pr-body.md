## Summary

- `install-git-hooks.sh` bakes the install-time plugin version dir into the generated pre-push hook as a literal absolute path — confirmed live that a hook installed under v0.9.0 was still running v0.9.0's `otta-gate.sh` while the plugin had moved on to v0.20.1. Every gate fix since (including #78/v0.20.1) was invisible to that repo.
- The generated hook now resolves the newest sibling version dir under the plugin's cache root at RUN time (falls back to the install-time path if the layout doesn't match), so it tracks upgrades automatically with no reinstall.

```acceptance
GIVEN a pre-push hook installed while plugin version V1 was current
WHEN the plugin cache later gains a newer version V2 (no hook reinstall)
THEN the hook execs V2's otta-gate.sh, not V1's
```
